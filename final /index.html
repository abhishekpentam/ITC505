How to Play Student Notes

The goal of Lights Out is simple: switch off every light on the grid. A tile can be either on (glowing) or off (dark).

Rules
  • Click any tile to toggle it.
  • The clicked tile and its up / down / left / right neighbors flip.
  • You win when all 25 tiles are dark.
Implementation highlights
  • The board is built dynamically in JavaScript as a 5 × 5 grid.
  • Each click uses a single function to toggle a cross-shaped pattern, re-used during randomization.
  • The starting state is guaranteed solvable by performing a series of random simulated moves on an all-off board.
  • A move counter, win overlay, and window.alert("You win!") give feedback when the puzzle is solved.
Fonts & styling

The page combines a retro arcade title font with a clean body font delivered via a web font service. The board uses gradients, glow effects, and subtle animations to make the state changes visually clear while maintaining accessibility.
